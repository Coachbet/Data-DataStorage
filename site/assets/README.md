# Site assets

- `logo.svg`: the project mark, drawn for this project: a V on an ink square with
  one amber square, the colour used for abstention across the site. It is used as
  the browser icon and beside the site name. It represents the project, not a
  measured transfer.
- `fonts/`: Source Sans 3 and Source Serif 4 (variable, Latin subset), both under
  the SIL Open Font License 1.1; the licence texts are next to the files. The
  fonts are embedded in the page, so the site makes no external request.
