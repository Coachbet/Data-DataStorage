# Presentation workspace

Keep editable slide sources here and put generated exports in `docs/archive/presentation/build/`.
The final 15-minute presentation must remain consistent with the code and report.

Suggested evidence-first sequence:

1. precise question and why it matters;
2. data provenance and acquisition performed by the team;
3. data-quality diagnosis and justified cleaning;
4. storage choice compared with at least one alternative;
5. analysis and results;
6. limitations, especially ecological inference;
7. answer to the question and reproducibility handoff.
