# Quality of the candidate reference table

Written on 15 November 2026 as a complement to
[`data_quality_and_cleaning.md`](data_quality_and_cleaning.md), which is kept
exactly as submitted on 3 November 2026 and covers the official election files.

The second peer review noted that our hand-coded table
(`data/reference/candidate_positions.csv`) decides which finalist each eliminated
group is assigned to under H1 and H2, yet had no row in that assessment. The
official counts are finished; this table is not. It is assessed here with the
same three characteristics. The figures are generated by `vote-transfer analyse`
into `reports/results/candidate_table_quality.json`; this document names the
checks and does not copy the numbers.

| Characteristic | Metric | Status |
|---|---|---|
| Accuracy | Agreement between two independent coders: percentage and quadratic-weighted kappa, with the confusion matrix and the list of disagreements (`vote-transfer review-agreement`) | **[PENDING: coder agreement]** The kit is ready in `data/reference/review/`; no human coding has been done, so no figure exists |
| Consistency | The same party label carries the same family in every election | Flags the PS (Hamon's 2017 candidacy is coded differently from the other PS candidacies) and the UDF (Bayrou in 2002 and in 2007). Both are documented choices in the coding notes; the reviewers must confirm or change them |
| Completeness | Rows without a score | The two Cheminade records (2012, 2017). Treatment fixed before any result: these groups use the H0b row in H1 and H2 |

**Response.** As for the election data, we flag and report; we do not edit codes
to remove a flag. No code may be changed to improve model fit. Until both coders
have finished, every row stays `draft` and every H1–H3 result is labelled
"draft coding". The effect of the coding on the conclusions is measured by
rerunning every model on the `alternative_family` column
(`reports/results/sensitivity.csv`). That rerun moves all listed rows at once,
finalists included: it is one alternative scenario, not a per-candidate
sensitivity analysis.
